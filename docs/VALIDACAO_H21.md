# Validação da H21 Final

## Estado

- Produto: TS SE Tool Community `0.3.11.47 — RC5.1H21 Final`.
- Plataforma validada: Windows com **Euro Truck Simulator 2 1.60**.
- Save moderno principal validado: **formato 97**.
- Inicialização da revisão final R4: confirmada sem erros pelo mantenedor.
- ATS: não testado e não homologado.

## Critérios herdados da linha homologada

A linha H20 validou carregamento, staging, writer moderno, persistência, recarga e diffs cirúrgicos para habilidades de motoristas. A linha H19.3 validou o editor de acessórios com alterações restritas a `data_path` e `refund`.

## Limites

A validação comunitária comprova a combinação **ETS2 1.60 + save 97** usada nos testes. Ela não é uma garantia para toda versão futura do jogo, todos os DLCs ou todos os mods. Mantenha backups e relate regressões com logs e um caso reproduzível.
