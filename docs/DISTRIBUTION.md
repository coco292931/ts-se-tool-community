# Política de distribuição

O download oficial é a seção [GitHub Releases](https://github.com/fabiomesquita01/ts-se-tool-community/releases). Espelhos devem apontar para este repositório e não podem alterar o arquivo.

Toda divulgação deve informar:

- continuação comunitária gratuita e de código aberto;
- atribuição ao autor original LIPtoH;
- ETS2 suportado e ATS não validado;
- obrigação de backup e uso por conta e risco;
- versão e SHA-256 exatos;
- GitHub Issues como canal técnico;
- ausência de vínculo com a SCS Software.

Não use paywall, cadastro obrigatório, encurtador, wrapper de instalação, DLCs da SCS ou conteúdo pago de mods.
