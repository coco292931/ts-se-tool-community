# Política de segurança

## Relato privado

Não publique uma vulnerabilidade que possa permitir execução arbitrária de código, atualização maliciosa ou modificação destrutiva de saves.

Envie um relato privado para `fabiomalmsteen@gmail.com` contendo versão afetada, passos de reprodução, impacto, evidências e possível mitigação.

## Integridade das versões

Binários oficiais são distribuídos somente em GitHub Releases. Confira `SHA256SUMS.txt`. O projeto não distribui jogos, cracks, DLCs ou conteúdo pago de terceiros.
